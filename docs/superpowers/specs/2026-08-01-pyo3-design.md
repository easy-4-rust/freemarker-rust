# pyo3 集成设计

- **日期**：2026-08-01
- **作者**：freemarker-rust 团队
- **状态**：已实施
- **上游基线**：freemarker-jython25（jython20 桥接实现，13 文件）
- **依赖**：PyO3 0.29.0、核心引擎（freemarker crate）

## 1. 目标与范围

将 Java freemarker-jython25 迁移为 Rust freemarker-pyo3：FmConfiguration/FmTemplate（pyclass）、PyObjectWrapper（JythonWrapper 等价）、类型矩阵（wrap/unwrap/TemplateModelAdapter）、GIL 策略、异常桥接。

详细设计见：`docs/10-pyo3集成设计.md`

## 2. 设计来源

| 文档 | 路径 | 核心内容 |
|------|------|----------|
| pyo3 集成设计 | `docs/10-pyo3集成设计.md` | 模块与 API 面（#[pymodule] freemarker）、FmConfiguration/FmTemplate（pyclass）、PyObjectWrapper（JythonWrapper 等价）、wrap 类型矩阵（10 文档 S2 表）、unwrap 方向 + TemplateModelAdapter、GIL 策略（单次持有 + allow_threads）、异常桥接（PyErr <-> TemplateError）、Python 黄金套件、maturin 打包 |

## 3. 关键设计决策

- **GIL 策略**：单次持有 + allow_threads 分段
- **异常桥接**：PyErr <-> TemplateError + 自定义 FreeMarkerError
- **TemplateMethodModelEx::exec 加 env 参数**：Java 线程局部 -> Rust 显式传参
- **maturin 打包**：Trusted Publishing 发布到 PyPI

## 4. 验收标准

1. Python 套件 100%
2. 双向类型矩阵全过
3. 双向异常消息完整
4. 多线程无死锁
