# 12 - 迁移路线图与任务分解

> 阶段划分：P0 骨架 → P1 解析 → P2 渲染核 → P3 表达式+内建 → P4 配置/缓存/格式 → P5 pyo3 → P6 打磨。
> 每阶段含：任务清单（WBS）、验收标准（引用对应文档）、工作量估算（人·日，单人熟练 Rust + 熟悉 FreeMarker 语义）。

## 依赖关系图

```
P0 ──► P1 ──► P2 ──► P3 ──► P4 ──► P6
  \                 \       └──► P5 ──► (P6 包含 pyo3 打磨)
   └──► (L3 对比 harness 随 P2 就绪)
```
