# 10 - pyo3 集成设计（freemarker-pyo3）

> 目标：`freemarker-jython25` 的 Rust 等价物。语义参考实现 = `freemarker-jython20/src/main/java/freemarker/ext/jython/`（13 文件，jython22/25 仅版本适配器）。
> PyO3 **0.29.0**（`https://docs.rs/pyo3/0.29.0/pyo3/`，`https://github.com/pyo3/pyo3`）

## 1. 模块与 API 面

```rust
// lib.rs —— #[pymodule] freemarker
#[pyclass] pub struct FmConfiguration { inner: Arc<freemarker::Configuration> }
#[pymethod] new / set_shared_variable / get_template(name) -> FmTemplate / ...
#[pyclass] pub struct FmTemplate { inner: Arc<Template> }
#[pymethod] process(root: PyObject, out: Option<PyObject>) -> PyResult<String>
// 渲染入口统一返回 str（可再包装 StringIO 输出目标）

// wrapper.rs —— JythonWrapper 等价
pub struct PyObjectWrapper {
    attributes_shadow_items: bool,
    use_cache: bool,
}
impl freemarker::wrapper::ObjectWrapper for PyObjectWrapper { ... }
```

对应 Java 用法映射：

| Java（Jython） | Python（pyo3） |
|---|---|
| `new Configuration(VERSION)` | `fm.Configuration()`（默认 incompatibleImprovements=2.3.34） |
| `cfg.setObjectWrapper(new JythonWrapper())` | `cfg.object_wrapper = fm.JythonWrapper()`（构造参数） |
| `cfg.setSharedVariable("x", ...)` | `cfg.set_shared_variable("x", obj)` |
| `Template.process(dataModel, writer)` | `tmpl.process(data)` → str |
| `JythonWrapper.wrap(obj)` | 内部：`Py<PyAny> → TModel` |
| `JythonWrapper.unwrap(model)` | 内部：`TModel → PyObject`（见 §3） |

## 2. wrap 方向（Python 对象 → TModel）—— 对应 `JythonModelCache.create`

| Jython 判定 | Python（pyo3）判定 | TModel 角色 | 说明 |
|---|---|---|---|
| `PyDictionary/PyStringMap` | `is_instance_of::<PyDict>` | hash | SimpleHash 视图：`get_item(key)` 惰性；`?keys/?values` 调 `keys()`/`values()` |
| `PySequence` | `is_instance_of::<PyList/PyTuple>` | sequence + collection | `get_item(i)` 惰性索引；迭代走 `PyIterator` |
| `PyInteger/PyLong/PyFloat` | `is_instance_of::<PyInt/PyFloat>` | number | `extract::<i64/u64/f64>()`；溢出 → 大整数（`PyLong` 直接转 `BigInt`：`to_string` 解析） |
| `PyNone` | `is_none()` | nothing（null） | `${x}` 缺失语义 |
| `PyString/PyUnicode` | `is_instance_of::<PyString>` | scalar | `extract::<String>()` |
| `PyBoolean` | `is_instance_of::<PyBool>` | boolean | `is_truthy()` |
| `PyDatetime/PyDate` | `is_instance_of::<PyDateTime/PyDate>` | date | `extract::<PyDateTime>` → chrono（含 tzinfo → 时区设置；naive → 按环境时区） |
| 可调用 | `is_callable()` | method + scalar + boolean（多角色） | 对应 JythonModel 六合一 |
| 其他对象 | — | 通用模型（多角色槽位） | 对应 JythonModel：`getattr`/`get_item` 双通道 |
| PyInstance（py2 类实例） | 不需要 | — | py2 语义已消亡；`__tojava__` 探测 → pyo3 的 `downcast`/`extract` 按需 |

**通用模型（对应 `JythonModel.java`）**：

```rust
pub struct PyObjectModel {
    obj: Py<PyAny>,
    wrapper: Arc<PyObjectWrapper>,
    // 角色槽位在 TModel 中标记：scalar+boolean+hash+method 全部可用
}
// get(key)：attributes_shadow_items ? getattr → get_item : 反序   （JythonModel.get :95-115）
// exec(args)：obj.call1(call_args)                                  （JythonModel.exec）
// as_boolean：is_truthy()                                          （__nonzero__）
// as_string：str()                                                 （toString）
// is_empty：len()==0                                               （__len__）
```

## 3. unwrap 方向（TModel → Python 对象）—— 对应 `JythonWrapper.unwrap` + `TemplateModelToJythonAdapter`

| TModel 角色 | Python 对象 | 对应 Java |
|---|---|---|
| `AdapterTemplateModel`（pyo3 包装的 Python 对象） | 原 `Py<PyAny>`（身份还原） | `Py.java2py(getAdaptedObject)` |
| scalar | `str` | `PyString` |
| number | `int`（整数）/ `float`（浮点）/ `decimal.Decimal`（Decimal —— **决策 D5**） | `PyLong`/`PyFloat`（BigInteger→PyLong） |
| boolean | `bool` | PyBoolean |
| date | `datetime`（带 tzinfo 或 naive） | PyDate |
| hash | `dict`（键值对迭代）或**通用适配器** | TemplateModelToJythonAdapter.`__finditem__` |
| sequence | `list` 或**通用适配器** | `__finditem__(int)` |
| method | **通用适配器**（`__call__`） | `TemplateModelToJythonAdapter.__call__` |
| nothing | `None` | PyNone |
| 其他/组合 | **通用适配器** | `TemplateModelToJythonAdapter` |

**通用适配器（对应 `TemplateModelToJythonAdapter`，pyo3 等价）**：

```rust
#[pyclass] pub struct TemplateModelAdapter { model: TModel }
#[pymethods]
fn __getitem__(&self, key: &Bound<PyAny>, py: Python) -> PyResult<PyObject> {
    // int → sequence.get(i)；str → hash.get(key)（PyInteger/PyString 双分派，对应 __finditem__ 重载）
}
fn __call__(&self, args: &Bound<PyTuple>, kwargs: Option<&Bound<PyDict>>, py: Python) -> PyResult<PyObject> {
    // TemplateMethodModel(Ex).exec：参数逐个 wrap 回 TModel（非 Ex 变体参数转 str —— 兼容分支）
}
fn __len__(&self) -> PyResult<usize> { /* sequence.size() / hash_ex.size() */ }
fn __bool__(&self) -> PyResult<bool> { /* boolean / size>0 / !is_empty */ }
```

## 4. GIL 策略（决策 D4）

**原则**：渲染过程中 Python 对象访问频率高，逐次 `Python::with_gil` 开销大 → **渲染入口持有单次 GIL**：

```rust
// freemarker-pyo3 渲染路径
pub fn process(&self, py: Python<'_>, data: PyObject) -> PyResult<String> {
    // 1. 在 GIL 内：wrap data → TModel（零拷贝 Py<PyAny> 引用）
    // 2. 渲染：核心引擎在 Rust 侧执行；遇到 Py 模型操作时直接使用
    //    已持有的 py 句柄（通过 thread-local 或显式传递 &Python）
    // 3. 大段纯文本/纯 Rust 处理可用 py.allow_threads() 释放 GIL
}
```

- **GIL 传递**：`freemarker` 核心 crate 不感知 GIL。方案：`PyObjectModel` 方法签名接收 `Python` token —— 由 pyo3 crate 的调用方持有；跨线程要求调用方保证（`Send` 约束：`Py<PyAny>` 满足）。
- **`allow_threads`**：仅对不触碰 Python 对象的渲染段（纯文本输出、字符串内建）使用；触碰 Py 模型前必须重新获取。
- **多线程**：`FmTemplate`/`FmConfiguration` 是 `Send + Sync`；Python 侧多线程渲染安全（GIL 串行化 Python 访问）。

## 5. 异常桥接（`errors.rs`）

| Python 异常（`PyErr`） | TemplateError → Python |
|---|---|
| wrap 时 `getattr`/`get_item` 抛 `AttributeError`/`KeyError` | 按 `attributes_shadow_items` 语义继续尝试另一通道；两者皆失败 → `TemplateModelException`（Python 异常作为 cause，`PyErr` 保留 traceback 并 `normalize` 后 `to_string` 嵌入消息） |
| `__call__` 抛任意 `PyErr` | → `TemplateError::Model`（消息含 Python 异常类型与详情） |
| 模板错误 → Python | `TemplateError` → `PyRuntimeError`（或自定义 `fm.FreeMarkerError` 异常类，消息 = 完整 Java 风格错误文本；**推荐自定义异常**便于 Python 侧按类型捕获） |

## 6. 与 Java 版的语义差异清单（记录并测试）

1. **py2 遗留**：`PyInstance`/`__tojava__`/`Py.NoConversion` 无对应（py3 无实例对象模型）；`isPyInstance` 分支删除。
2. **`Decimal`**（D5）：Java `BigDecimal → PyLong`（`OptimizerUtil.optimize` 后整数化）；Rust：Decimal 整数 → `int`；非整数 → `float`（或 `decimal.Decimal`，需 Python 侧 import —— 默认 float，可用配置切换）。
3. **版本适配器**：`JythonVersionAdapterHolder` 反射机制整个删除（PyO3 编译期绑定 CPython ABI）。
4. **`?keys`/`?values`**：Java 调 Python `keys()`/`keySet()`；pyo3 调 `keys()`/`values()`（py3 无 `keySet`），失败消息对齐（含类名）。
5. **`JythonRuntime`/`ext/ant`**：不迁移。
6. **GIL 差异**：Jython 单线程语义 vs CPython GIL —— 行为等价，性能注意点见 §4。
